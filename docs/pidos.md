# Pi-DOS

**A dedicated DOS experience for Raspberry Pi.**

Pi-DOS boots your Raspberry Pi directly into a DOS-compatible environment for classic games, applications, and demos. Built around DOSBox-X and a minimal Linux system, it includes persistent storage and a built-in configuration utility.

Pi-DOS is a standalone side project by Rubén Tomás Alonso (RTA), the creator of RePlayOS.

!!! info "Development status"
    Pi-DOS is under active development. Hardware testing and compatibility work are ongoing. See the GitHub repository for current hardware requirements and project status.
